# Phase L — Ready for Review backlog (after 24/7 ready)

**Not infrastructure.** Founder runs this only after the department is operationally ready.

Current backlog (~26 `waiting_founder`) was intentionally left untouched during activation.

## Lightweight strategy

For each Resume Template in Ready for Review:

| Action | When |
|--------|------|
| **APPROVE** | Meets brand bar; eligible for release/publication path |
| **REQUEST CHANGES** | Fixable layout/content; dispatcher revises unattended |
| **REJECT** | Wrong direction; do not publish |

## Rules

- Do not raise `queue_max` to “clear” pressure — drain via decisions.
- Prefer small daily batches (e.g. 5–10 reviews/day) until `waiting_founder < 20` so scheduled generation resumes producing into FR.
- Memory promotion happens on APPROVE of revised lineages; do not bulk-approve without review.
