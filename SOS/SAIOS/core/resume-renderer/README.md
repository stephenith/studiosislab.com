# Resume Renderer Engine V1

Deterministic executor of DesignBrief **Resume JSON** instructions.

```
DesignBrief → Resume JSON → Resume Renderer → Render Tree → Canvas JSON → Preview → Founder Review
```

## Rules

- Executes instructions only — no redesign, no Brain, no AI
- Never modifies DesignBrief
- Dry-run only · no LIVE · no OpenAI · no publish

## Run

```bash
npm run resume-renderer:verify
```
